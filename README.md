# GazApi

REST API для приёма и анализа показаний устройств.

## Возможности

- Сохранение показаний x, y, z с идентификатором устройства и временем записи.
- Расчёт количества, минимума, максимума, суммы и медианы.
- Статистика отдельно для x, y и z.
- Выбор периода или расчёт за всё время.

## Запуск

Необходим Docker с Docker Compose.

Скопируйте .env.example в .env и задайте DB_PASSWORD.

В PowerShell:

```powershell
Copy-Item .env.example .env
docker compose up --build -d
```

Документация API: http://localhost:8080/docs

## Запросы

POST /devices/{device_id}/pokazaniya

Пример тела:

```json
{"x": 1.5, "y": -2.0, "z": 7.3}
```

GET /devices/{device_id}/statistics

Необязательные параметры: start и end.
Даты должны содержать часовой пояс, например 2026-10-11T00:00:00Z.

Начало периода включается, конец исключается.
Без дат возвращается статистика за всё время.

При отсутствии показаний количество и сумма равны нулю,
минимум, максимум и медиана равны null.

Время записи назначается PostgreSQL при сохранении показания.

## Хранение данных

PostgreSQL хранит данные в Docker volume.
Таблица и индекс создаются автоматически при первом запуске.

## Остановка

```powershell
docker compose down
```


## Пользователи и устройства

POST /users — создание пользователя.

Пример тела:
{"name": "Максим"}

POST /users/{user_id}/devices — регистрация устройства пользователя.

Пример тела:
{"device_id": "sensor-1"}

Перед отправкой показаний устройство необходимо зарегистрировать.
Каждое устройство принадлежит одному пользователю.

GET /users/{user_id}/statistics — общая статистика
по показаниям всех устройств пользователя.

GET /users/{user_id}/devices/statistics — статистика
отдельно для каждого устройства пользователя.

Обе ручки статистики поддерживают необязательные параметры start и end.
Начало периода включается, конец исключается.

Для несуществующего пользователя возвращается 404.
При повторной регистрации устройства возвращается 409.
Для незарегистрированного устройства отправка показаний возвращает 404.

Устройства без показаний отображаются в отдельных результатах:
количество и сумма равны 0, остальные показатели — null.
Пользователь без устройств получает пустой список devices.
